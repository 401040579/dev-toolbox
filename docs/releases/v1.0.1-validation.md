## Review record

- Bounded team: root plus one reviewer/implementer, no further fan-out. The reviewer first reproduced unit/YAML/TOML defects in real Chromium, then implemented only the assigned structured converters and later strict IP parsing. Root inspected those changes and their semantic tests.
- The reviewer independently examined root changes and found two candidate regressions: saved Pipeline IDs required `crypto.randomUUID` on insecure HTTP, and rounding MAX_VALUE produced Infinity. Both were corrected and received targeted regressions, including an actual HTTP-origin browser save.
- A later read-only UI audit found the preset/IP text omissions in P-02 and identified the coverage blind spot: translated titles and absence of raw keys alone do not prove internal strings were translated. Explicit preset/result assertions now complement all-tool initial rendering and source-key checks. This is not a claim that every output/error path of all 86 tools was exhaustively audited.
- Real desktop English TOML, mobile Chinese Cron and mobile English Pipeline screenshots were inspected from production preview. Narrow-screen tests check document width for presets, structured converters and IP results. Wide binary/IP values scroll inside their result tables.

## Supported boundaries and distribution

- YAML 1.2 core types, string mapping keys and JSON-compatible values; reject unsupported tags, duplicate keys, circular aliases and unrepresentable numbers. TOML root must be an object; null and unquoted date/time values reject rather than being silently dropped or rewritten. Quoted dates/times preserve text. Comments are not retained.
- Structured data limits: 1 MiB UTF-8 input, 4 MiB output, 64 levels, 50,000 values and 100 expanded YAML alias references. Integers beyond JavaScript's safe range reject; use quoted strings for exact large values.
- IP supports decimal IPv4 and hexadecimal IPv6 groups with optional `::`; IPv4 octets with leading zeroes remain decimal. Dotted IPv4-mapped IPv6, zone IDs and CIDR suffixes are not accepted here. Existing address labels are coarse categories, not a routability guarantee.
- JWT/OAuth decoding does not authenticate tokens. “Not expired” only describes the decoded timestamp. Color-blindness preview is an approximation; unsupported prevalence claims were removed.
- `yaml 2.9.1` is ISC; `smol-toml 1.9.0` is BSD-3-Clause. Generated notices retain complete licenses for 108 installed packages plus Twilio. No licenses were relabeled as project MIT.
- The existing large entry-chunk warning remains visible (about 753 kB minified, 248 kB gzip). The YAML parser is a separate on-demand chunk; a broader catalog/locale loading redesign is deferred.
- Automated browser coverage targets Chromium. Firefox, Safari, device installation and actual carrier billing remain outside certification. The v1.0.0 privacy, preview/export and offline boundaries continue to apply.
