## Review and boundaries

- Bounded team: root plus three workers, no further fan-out. Workers implemented JSON diff, log analysis and Smart Paste; root implemented shared drafts, migrated existing editable state and integrated the four workflows. Cross-review reproduced W-03/04/07/10 before fixes. Each received a focused regression; the draft reviewer then checked the corrected cleanup/StrictMode paths without expanding scope.
- Drafts default to enabled and remain browser-local. The per-tool budget is 524,288 serialized JSON characters including options. Debounce is 300 ms, with navigation/pagehide flush. Oversized or denied writes preserve session input and show a truthful status; clearing preserves preferences and explicitly saved Pipelines. Password/key fields and generated credentials are excluded by field selection, not by inspecting arbitrary pasted content. Imported log/Data URL text follows text-input rules. Pipeline retains its existing explicit save workflow.
- JSON diff limits per side: 1 MiB UTF-8, 20,000 values and 64 levels. Reports allow 500 changes, 4,096-character paths and 4 MiB serialized output. Added/removed subtrees count as one change. Object key order is ignored; array order, types and missing/null are distinguished. Duplicate keys follow JSON.parse's last-value rule. Exact large numbers/high-precision decimals should be represented as strings. Filter selection changes only the view, never exported content.
- Log input is limited to 10 MiB. At most 100,000 records are indexed; remaining original text is retained as an unknown block with a notice. Pages show 100 records and previews show at most 4,000 characters per record; copy/download retains complete text. The supported formats are ISO-like text timestamps and common JSONL fields/IDs, including Pino levels. This is heuristic log inspection, not a universal vendor-format parser. Timestamps without offsets and time-filter controls use the browser's local zone.
- Smart Paste accepts up to 1 MiB UTF-8 and recommends JSON objects/arrays, structurally valid JWT, conservative Unix seconds/milliseconds, HTTP(S) URLs, readable-text Base64 or plain text. JWT recognition does not authenticate a token. Input is transferred once through tab memory, expires after five minutes and is never placed in the URL. The selected target follows draft settings. Clipboard access requires a click; no background polling is used.
- Production processing remains in the browser; no service or dependency was added. Notices retain the licenses of 108 packages plus Twilio. The pre-existing large entry-chunk warning remains visible (about 781 kB minified / 258 kB gzip); the JSON UI, log UI and log Worker are separate chunks. A broader catalog/locale loading redesign is outside this release.
- Browser automation targets Chromium, including 390px and 1280px checks. Existing preview/export, offline and crypto boundaries continue to apply; this is not certification for every browser or every output path of all 88 tools.

```bash
node scripts/check-release-upgrade.mjs release-assets/dev-toolbox-v1.0.1-site.zip
```
