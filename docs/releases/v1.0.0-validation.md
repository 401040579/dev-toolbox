## Review record

- Self review: root Codex agent traced input → parser/transform → preview/export, network sinks, CSS style sinks, share hash → store → engine → React text consumers, and source licenses.
- One independent Codex reviewer, read-only, no further fan-out. It reproduced the baseline in Chromium: Markdown click marker `7`, animation marker `8`, SVG foreignObject error marker `11`, and SVG/gradient external sentinel requests. Detached HTML-entity textarea parsing produced neither execution nor requests and was excluded.
- Independent candidate review consumed current source-function output in Chromium HTML DOM and SVG images. No payload executed or fetched resources. Normal SVG gradient, clipPath, href/xlink:href and whitespace were preserved in minify/prettify modes; pixels inside both shapes were `[124,0,130,255]`, outside clip `[0,0,0,0]`. Normal Markdown structures and safe links remained usable. This complements, but does not replace, UI E2E.
- First full E2E exposed pre-existing translation/template defects and a test route typo; those were corrected. The final candidate SHA, Linux CI run, deployment result and release checksum are recorded in the release PR and GitHub Release; this file records the underlying findings and acceptance contract.

## Verification boundaries

Chromium is the automated browser target. Firefox, Safari, iOS/Android installation and actual carrier billing are not independently certified. SMS segmentation is an estimate (provider encoding, concatenation headers and billing policies vary). Offline use depends on successful initial precaching and browser storage. Legacy formatter/converter tools are lightweight utilities; verify important protocol results independently.

## Release preparation findings

- **F-10 (verified):** Independent review simulated the actual Pages 404 → `?/` redirect and reproduced a double-slash origin error and stale Router state. Recovery now happens before Router creation, joins the path once, rejects external/protocol-relative targets and preserves query/hash. Two browser regressions use the actual `public/404.html` bytes, including a shared Pipeline.
- **F-11 (verified):** The old PWA registered a waiting update without a user activation path. A bilingual update prompt now asks users to copy unsaved input before reload. Browser regression serves two service-worker revisions, activates the waiting worker through the real app button, and checks that the second revision controls the page. Older already-cached builds require closing all controlled tabs/app windows before reopening online; README documents this migration.
- **F-12 (verified):** SMS switches lacked an accessible name under the switch role. Explicit labels now support browser task checks and assistive interaction; language-toggle labels are localized.
- Release packaging includes complete referenced documentation, screenshots and source/license snapshots, alongside the static site, local SPA server and checksums. Build metadata marks dirty source checkouts; release packaging rejects dirty/old builds.
- Existing lint errors were removed with equivalent regex ranges, scoped declarations and unused-binding cleanup in `16eeb57`. Six legacy hook-dependency warnings remain visible (HexString, JwtDecode, ColorPicker, DiffViewer and two EpochConverter hooks); no new warning was hidden. Vite also reports the existing large main chunk. These are documented maintenance/performance limitations.
- Only one independent reviewer was used throughout. It additionally verified the notice generator's 106-package selection has no platform-specific/optional package entries, that generated text exactly matches the checked-in file, and that all fallback license snapshots equal the declared upstream SHA bytes. Private vulnerability reporting is enabled. HTTPS is enforced on the existing custom domain.
- **F-13 (verified):** The existing service-worker navigation fallback replaced direct metadata/license navigation with app HTML. It now excludes file paths. The controlled-worker regression checks actual JSON/text Content-Types for version metadata and both license/notice files after returning online.
